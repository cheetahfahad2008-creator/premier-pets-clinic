# 🐾 Premier Pets Clinic

A modern, fully responsive website for a veterinary clinic — built with plain HTML, CSS and JavaScript. No build step, no dependencies.

## Features

- **Hero section** with animated blob visual, floating info cards and trust badges
- **Services grid** — wellness exams, vaccinations, dental, surgery, emergency care, grooming
- **About section** highlighting the clinic's fear-free, transparent approach
- **Team cards** for the veterinarians
- **Testimonial slider** with autoplay, arrows and dots
- **Appointment booking form** with validation, past-date blocking and a success state
- **Animated stat counters**, scroll-reveal animations and an active-link navbar
- Mobile-friendly navigation and layouts, plus `prefers-reduced-motion` support

## Running locally

The whole site is a single self-contained file — just open `index.html` in any browser. No server, build step or extra files needed.

## Structure

```
index.html        # Complete site: markup, styles and scripts in one file
```
